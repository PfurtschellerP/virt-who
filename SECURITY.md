# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact the repository maintainers privately through
GitHub with the affected version, a description of the impact, and steps to
reproduce the issue.

Please avoid including credentials, tokens, or other sensitive data in a
report.

## Supported versions

Only the latest published image and Helm chart versions are actively
maintained. Historical releases are immutable and are not rebuilt
automatically.
